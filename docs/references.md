# Reference projects

BF Labs UI translates structural ideas from the following public projects while
keeping the BF Labs visual system authoritative.

## shadcn/ui

- Repository: <https://github.com/shadcn-ui/ui>
- Adopted idea: source ownership, registry-shaped delivery, semantic variables.
- Not adopted: its default visual theme or a requirement to use Tailwind.

## assistant-ui

- Website: <https://www.assistant-ui.com/>
- Repository: <https://github.com/assistant-ui/assistant-ui>
- Adopted idea: separate reusable state and behavior from product presentation.
- Not adopted: its full conversation runtime and broad integration package set.

## AI Elements

- Website: <https://elements.ai-sdk.dev/>
- Repository: <https://github.com/vercel/ai-elements>
- Adopted idea: focused AI components, direct examples, and component-level
  interaction verification.
- Not adopted: framework assumptions that are unnecessary for the BF Labs core.

## Ant Design X

- Website: <https://x.ant.design/>
- Repository: <https://github.com/ant-design/x>
- Adopted idea: organize AI interfaces around expression, process,
  confirmation, and feedback.
- Not adopted: its default colors, gradients, rounded geometry, or product tone.
